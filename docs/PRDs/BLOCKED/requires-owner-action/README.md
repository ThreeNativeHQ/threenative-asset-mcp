# Blocked: requires owner action

PRDs whose only remaining work is a `## Blocked on` item that only João can clear (a Fab browser
challenge, a licence or visibility decision, repository settings). Each file keeps its ticked
boxes and their evidence, with `**Status:** PARTIAL` and a `**Blocker:**` line naming the action.

When the blocker clears, move the file back to `docs/PRDs/` (or finish it and move it to
`docs/PRDs/done/`) in the PR that does the remaining work.
